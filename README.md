# 🎓 Student Management System

A GUI-based Student Management System developed using Python, Tkinter, Pandas, and Excel.

## 📌 Features

- Add Student Records
- Search Student Details
- Update Student Information
- Delete Student Records
- Excel-Based Data Storage
- Auto Load Data
- Interactive Table View
- Data Validation

## 🛠 Technologies Used

- Python
- Tkinter
- Pandas
- OpenPyXL
- Excel

## 🚀 Project Outcome

This project helps manage student records efficiently through a user-friendly graphical interface. It supports complete CRUD operations and stores data in Excel format.
